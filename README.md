# Ascriibe\_Engine-SDL2



afin de faire fonctionner le moteur, il faut entrer les commandes suivante au premier lancement
de visual



commande de build cmake : 

* mkdir build
* cd build
* cmake .. -G "Visual Studio 17 2022"
* cmake --build .



Chaque build devra être effectué via les commande suivante:

* cd build (Seulement si vous ne vous trouvez pas dans le dossier /build)
* cmake --build .
